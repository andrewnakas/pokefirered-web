Pokemon FireRed

Built from the pret decompilation. Bring your own cartridge dump.

Choose your ROM click, or drop a .gba file here

Your file is read in this browser only. It is loaded into memory with the File API and handed straight to the emulator — there is no upload, no server call, and no copy kept on disk. Reload the page and you will be asked for it again. In-game saves are kept, in this browser.

Which dumps are recognised

Any other GBA file still boots — it is just not checked. The sha1 is computed locally with the Web Crypto API.

Pokemon FireRed Keys: Arrows move · Z A · X B · A/S L/R · Enter Start · Shift Select. Gamepads and touch work too.
